# Livin' On Sweets Editor 1.0

This package contains the editor that is used in debug builds of Livin' On Sweets : Native

The game package will look for the editor DLL upon initialization to inject the DebugContainer and enable the Debug features 

Please note that this is just an adaptation of the Editor available on the old stable branch of Livin' On Sweets : Native
