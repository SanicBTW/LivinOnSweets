# Livin' on Sweets Unnoficial Port

This repository has been set to public due to the recent announcement of Sugar Rus (the former name of the "-ive Alive" event for Blue Archive) will apparently receive an [update](http://youtube.com/post/UgkxjfPiDNVPcOiu3XeAnBFiUtNpogUXLz05?si=fSM2EdYimf7KCdSf)

For the sake of preservation, this port will be kept on being developed, offering an alternative to the official version but potentially getting cancelled.

Please visit the [Notion](https://sancobtw.notion.site/Livin-on-Sweets-Unofficial-port-2a1f87f9cb60808cae5dcbe7a50a43ca?source=copy_link) for a more in-depth explanation and information over the project

It was a long and fun journey, now only the future awaits with more surprises.
